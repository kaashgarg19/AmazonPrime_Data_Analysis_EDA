# Amazon Prime Data Analysis

A small exploratory data-analysis project looking at a dataset of Amazon Prime movies and TV shows.

## What I looked at
- Movie and TV show distribution
- Release years
- Languages
- IMDb ratings
- Running time
- Maturity ratings

## My work

I loaded the data, checked its structure, cleaned fields where needed, explored different variables and created visualisations to understand the patterns in the dataset.

## Tools
Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter

## Notebook

The main analysis is in [Amazon_Prime_EDA.ipynb](Amazon_Prime_EDA.ipynb).

The notebook was originally developed in Google Colab. It is kept here as the main record of the analysis.

## Project note

This is an exploratory project. The observations in the notebook describe this dataset and should not be treated as conclusions about Amazon Prime's full catalogue.
