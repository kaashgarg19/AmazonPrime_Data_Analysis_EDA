# Amazon Prime Data Analysis

A data-analysis project exploring an Amazon Prime movies and TV shows dataset.

## About

The project uses Python to explore the content available in the dataset and identify patterns in areas such as:

- Movie and TV show distribution
- Languages
- IMDb ratings
- Running time
- Release year
- Maturity ratings

## What I worked on

- Loading and inspecting the dataset
- Cleaning and preparing the data
- Exploring different fields
- Creating visualisations
- Comparing patterns in the data
- Summarising findings

## Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Notebook

The main analysis is available in [Amazon_Prime_EDA.ipynb](Amazon_Prime_EDA.ipynb).

The notebook was originally developed using Google Colab. The repository keeps the notebook as the main record of the analysis.
