# Amazon Prime Data Analysis — EDA

This is an exploratory data-analysis project using a dataset of Amazon Prime movies and TV shows.

I built this project to practise working through a dataset from start to finish: loading it, checking the fields, cleaning where necessary, exploring patterns and making charts.

## Questions I explored

- How are movies and TV shows distributed?
- How do release years vary in the dataset?
- What languages appear?
- How are IMDb ratings distributed?
- What does the running-time data look like?
- How are maturity ratings represented?

## Notebook

The main analysis is in [Amazon_Prime_EDA.ipynb](Amazon_Prime_EDA.ipynb).

The notebook was originally developed in Google Colab and is kept here as the main record of the work.

## Tools

Python · Pandas · NumPy · Matplotlib · Seaborn · Jupyter

## Project note

This is exploratory work on a third-party dataset. The observations describe the dataset used in the notebook; they should not be read as a complete analysis of Amazon Prime's catalogue.

I have kept the notebook itself as the source of the analysis instead of adding a separate set of conclusions that are not directly supported by it.
